Entry for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty on make.fun: exactly one funny line, judged head to head by a comedy-club judge model.

## The line

> My smart fridge sighs every time I open it at 2 a.m., which is officially the closest thing I have to a relationship.

## How it works

`main.py` prints the line to stdout and writes it to `/output/entry.txt`. The line is 117 characters, inside the 1–200 character gate.

Run it with:

```sh
python3 main.py
```
